# 🌸 Portafolio Profesional - Adania Campos

Sitio web personal y portafolio profesional para **Adania Campos**, Estudiante de Licenciatura en Psicología. Diseñado con una estética cálida, limpia y minimalista, enfocado en destacar su experiencia clínica, voluntariado y habilidades en acompañamiento psicológico.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la página.
* **Tailwind CSS (v3 via CDN):** Diseño responsivo, estilos personalizados y paleta de colores pastel.
* **Google Fonts:**
  * *Playfair Display* (Encabezados y títulos).
  * *Plus Jakarta Sans* (Lectura de cuerpo y textos generales).
* **GitHub Pages:** Alojamiento web estático y despliegue continuo.
